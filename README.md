# エオルゼア天気帳

現実の空気を、冒険の景色に。気象庁アメダスの観測値を確認し、いまの気温をFFXIVの地域やキャラクターに重ねて楽しむ、非公式・非営利のお天気ツールです。

公開URL: https://spthx.github.io/eorzea-weather/

## 見られるもの

- 選択地点の気温・湿度・風速・1時間降水量・積雪深
- 四季に対応したFF14のたとえと公式資料へのリンク
- 気象庁の台風・熱帯低気圧一覧、実況、勢力、予報
- 全国の高温・低温・雨量・風速ランキング
- 気温のスライダーでたとえを試すプレビュー
- 結果の共有と専用のリンクプレビュー画像

表示値は端末の位置そのものではなく、アメダス観測地点の値です。降水なしを晴天、積雪ありを降雪中とは判定しません。天気予報、進路図、警報・注意報、雨雲の動きは気象庁の公式画面にリンクしています。

## 四季の表現

実際の観測気温で表現を選びます。以前の湿度・風による独自の摂氏補正は使いません。

| 観測気温 | たとえ |
|---|---|
| −15℃未満 | 極シヴァの冷気 |
| −15℃以上、−5℃未満 | パゴスの氷雪 |
| −5℃以上、0℃未満 | ガレマルドの冬 |
| 0℃以上、5℃未満 | イシュガルドの冷気 |
| 5℃以上、10℃未満 | クルザスの朝 |
| 10℃以上、15℃未満 | オルコ・パチャの涼風 |
| 15℃以上、20℃未満 | 黒衣森の木陰 |
| 20℃以上、25℃未満 | ラノシアの海風 |
| 25℃以上、28℃未満 | ウルダハの陽気 |
| 28℃以上、31℃未満 | サベネア島の熱気 |
| 31℃以上、41℃未満 | 炎を扱うキャラクターを0.5℃刻みで表示 |
| 41℃以上 | ゲロルト級の暑さ |

境界はサイト独自の創作であり、FFXIVの公式気温設定や医学的な体感温度ではありません。「酷暑日級」などは現在の観測気温に付けた演出名で、日最高気温による気象庁の統計区分とは異なります。

## 位置情報

緯度・経度は端末内で最寄りの気温観測地点を探すためだけに使用し、保存しません。観測地点ID・選択方法・保存時刻だけをブラウザに記憶します。次回は保存地点を表示し、位置情報を再取得しません。手動選択も保存します。移動時は「現在地を更新」を押してください。

現在地が未設定の場合は東京を仮表示します。東京が欠測の場合は、取得できた気温観測地点を表示します。

## 気象庁データ

アメダスと台風情報をブラウザから直接取得します。台風情報は気象庁のサイト用JSON（targetTc.json、各台風のspecifications.json）を使用します。公開APIとしての互換性保証はないため、取得失敗時には明示的なエラーと公式画面へのリンクを表示します。取得失敗を「台風なし」として扱いません。台風の詳細だけが取得できない場合は、一覧の項目を残して取得失敗を表示します。

アメダスは取得できない場合に前回のデータを表示します。前回データや3時間以上前の観測には古いデータである旨を表示します。台風情報は過去キャッシュで代用しません。
